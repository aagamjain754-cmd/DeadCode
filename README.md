#  DeadCode

> Everything has a story here. Visit "Skills" if you dare.

**DeadCode** is a horror-themed developer portfolio designed to feel more like an interactive experience than a traditional portfolio website.

It combines a dark cinematic interface, atmospheric animations, a mysterious intro sequence, and a hidden jumpscare triggered through the Skills section.

---

##  Features

-  Cinematic horror intro
-  Custom spider-web cursor
-  Dark horror-inspired interface
-  Red glow and glitch effects
-  Smooth scrolling navigation
-  Developer portfolio sections
-  Hidden Skills jumpscare
-  Jumpscare sound effect
-  Responsive design for different screen sizes
-  Built without frameworks or large libraries

---

##  The Experience

DeadCode starts with an introductory horror sequence.

A mysterious video appears with messages such as:

> "Something is watching..."

> "You shouldn't have come here."

> "Welcome to my portfolio."

The visitor can enter the website manually or wait for the intro to close automatically. :chatgpt-content-reference{index="2"}

Once inside, the portfolio contains:

- **HOME**
- **ABOUT**
- **PROJECTS**
- **SKILLS**
- **CONTACT**

The Skills section is intentionally different.

The navigation contains a small `?` beside Skills and a subtle visual effect, encouraging visitors to investigate it. :chatgpt-content-reference{index="3"}

###  The Skills Trap

The first time the visitor clicks **SKILLS**, the website triggers a jumpscare.

The JavaScript:

1. Stops the normal navigation.
2. Displays the jumpscare overlay.
3. Plays the jumpscare video.
4. Plays the sound effect.
5. Shakes the screen.
6. Hides the jumpscare after a short delay.
7. Finally scrolls to the Skills section.

The jumpscare is designed to happen only on the first click. :chatgpt-content-reference{index="4"}
